# Python Day 158 – Contact Management System

## Description
A Python-based Contact Management System that stores and manages contact information using CSV file handling.

## Features
- Add new contacts
- View all contacts
- Search by name or phone number
- Update contact details
- Delete contacts
- Prevent duplicate phone numbers
- Save records permanently

## Technologies Used
- Python
- CSV Module
- File Handling
- Lists and Dictionaries

## Files
- `contact_manager.py` – Main program
- `contacts.csv` – Contact records

## How to Run
Keep both files in the same folder and run:

```bash
python contact_manager.py
```

## Concepts Learned
CSV file handling, searching, updating records, deleting records, list comprehensions and input validation.
